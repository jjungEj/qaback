# 프론트엔드 HTML 테이블 → 이미지 변환 가이드

## 1. 라이브러리 설치

### React/Vue/일반 JavaScript
```bash
npm install html2canvas
# 또는
yarn add html2canvas
```

### CDN 사용 (HTML 파일에서 직접 사용)
```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/html2canvas/1.4.1/html2canvas.min.js"></script>
```

## 2. 기본 사용 방법

### React 예시

```jsx
import React, { useRef } from 'react';
import html2canvas from 'html2canvas';

function ExcelViewer({ htmlContent }) {
  const tableRef = useRef(null);

  const convertTableToImage = async () => {
    if (!tableRef.current) return null;

    try {
      // HTML 테이블을 Canvas로 변환
      const canvas = await html2canvas(tableRef.current, {
        backgroundColor: '#ffffff',
        scale: 2, // 고해상도를 위해 2배 스케일
        logging: false,
        useCORS: true,
      });

      // Canvas를 base64 이미지로 변환
      const imageBase64 = canvas.toDataURL('image/png');
      
      // "data:image/png;base64,..." 형식에서 base64 부분만 추출
      const base64String = imageBase64.split(',')[1];
      
      return base64String;
    } catch (error) {
      console.error('이미지 변환 실패:', error);
      return null;
    }
  };

  const handleConvertToJsonl = async () => {
    const imageBase64 = await convertTableToImage();
    
    if (!imageBase64) {
      alert('이미지 변환에 실패했습니다.');
      return;
    }

    // API 호출
    const request = {
      fileName: "example.xlsx",
      sheets: [
        {
          sheetName: "Sheet1",
          htmlContent: htmlContent,
          imageBase64: imageBase64  // base64 문자열만 전송
        }
      ]
    };

    try {
      const response = await fetch('http://localhost:8080/api/qa/convert/jsonl', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify(request)
      });

      const blob = await response.blob();
      const url = window.URL.createObjectURL(blob);
      const a = document.createElement('a');
      a.href = url;
      a.download = 'output.jsonl';
      a.click();
      window.URL.revokeObjectURL(url);
    } catch (error) {
      console.error('JSONL 변환 실패:', error);
    }
  };

  return (
    <div>
      {/* HTML 테이블 표시 */}
      <div 
        ref={tableRef}
        dangerouslySetInnerHTML={{ __html: htmlContent }}
        style={{ 
          display: 'inline-block',
          padding: '10px'
        }}
      />
      
      <button onClick={handleConvertToJsonl}>
        JSONL로 변환
      </button>
    </div>
  );
}
```

async function convertAllSheetsToJsonl(sheets) {
  const convertedSheets = await Promise.all(
    sheets.map(async (sheet) => {

        imageBase64: imageBase64
      };

    fileName: "example.xlsx",

## 6. html2canvas 옵션 설명

```javascript
const canvas = await html2canvas(element, {
  backgroundColor: '#ffffff',  // 배경색 (기본값: null = 투명)
  scale: 2,                     // 해상도 배율 (1 = 기본, 2 = 2배 고해상도)
  logging: false,               // 디버그 로그 출력 여부
  useCORS: true,                // 외부 이미지 로드 허용
  allowTaint: true,             // 외부 이미지 사용 시 canvas 오염 허용
  width: element.scrollWidth,   // 캡처할 너비
  height: element.scrollHeight, // 캡처할 높이
  windowWidth: window.innerWidth, // 뷰포트 너비
  windowHeight: window.innerHeight // 뷰포트 높이
});
```

## 7. 주의사항

### 1. 테이블이 화면에 보여야 함
- `display: none` 또는 `visibility: hidden`인 요소는 캡처되지 않습니다
- 스크롤 영역도 포함하려면 전체 요소를 캡처해야 합니다

### 2. 외부 리소스 (이미지, 폰트)
- 외부 이미지나 폰트를 사용하는 경우 `useCORS: true` 설정 필요
- CORS 정책에 따라 차단될 수 있음

### 3. 성능
- 큰 테이블의 경우 변환 시간이 걸릴 수 있음
- 로딩 표시를 추가하는 것을 권장

### 4. base64 문자열 형식
- `canvas.toDataURL()`은 `"data:image/png;base64,..."` 형식 반환
- 백엔드로 보낼 때는 `split(',')[1]`로 base64 부분만 추출해야 함

## 8. 완전한 예시 (React + TypeScript)

```tsx
import React, { useRef, useState } from 'react';
import html2canvas from 'html2canvas';

interface SheetData {
  sheetName: string;
  htmlContent: string;
}

interface ConvertRequest {
  fileName: string;
  sheets: Array<{
    sheetName: string;
    htmlContent: string;
    imageBase64: string;
  }>;
}

function ExcelToJsonlConverter({ sheets, fileName }: { sheets: SheetData[], fileName: string }) {
  const [loading, setLoading] = useState(false);
  const tableRefs = useRef<{ [key: string]: HTMLDivElement | null }>({});

  const convertTableToImage = async (htmlContent: string, sheetName: string): Promise<string | null> => {
    const tableElement = tableRefs.current[sheetName];
    
    if (!tableElement) {
      console.error(`테이블 요소를 찾을 수 없습니다: ${sheetName}`);
      return null;
    }

    try {
      const canvas = await html2canvas(tableElement, {
        backgroundColor: '#ffffff',
        scale: 2,
        logging: false,
        useCORS: true,
      });

      const imageBase64 = canvas.toDataURL('image/png');
      return imageBase64.split(',')[1]; // base64 부분만 추출
    } catch (error) {
      console.error('이미지 변환 실패:', error);
      return null;
    }
  };

  const handleConvertToJsonl = async () => {
    setLoading(true);

    try {
      const convertedSheets = await Promise.all(
        sheets.map(async (sheet) => {
          const imageBase64 = await convertTableToImage(sheet.htmlContent, sheet.sheetName);
          
          return {
            sheetName: sheet.sheetName,
            htmlContent: sheet.htmlContent,
            imageBase64: imageBase64 || ''
          };
        })
      );

      const request: ConvertRequest = {
        fileName: fileName,
        sheets: convertedSheets
      };

      const response = await fetch('http://localhost:8080/api/qa/convert/jsonl', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify(request)
      });

      if (!response.ok) {
        throw new Error('JSONL 변환 실패');
      }

      const blob = await response.blob();
      const url = window.URL.createObjectURL(blob);
      const a = document.createElement('a');
      a.href = url;
      a.download = `${fileName.replace(/\.[^/.]+$/, '')}.jsonl`;
      document.body.appendChild(a);
      a.click();
      document.body.removeChild(a);
      window.URL.revokeObjectURL(url);
    } catch (error) {
      console.error('변환 실패:', error);
      alert('변환에 실패했습니다.');
    } finally {
      setLoading(false);
    }
  };

  return (
    <div>
      {/* 각 시트의 HTML 테이블 표시 */}
      {sheets.map((sheet) => (
        <div key={sheet.sheetName}>
          <h3>{sheet.sheetName}</h3>
          <div
            ref={(el) => (tableRefs.current[sheet.sheetName] = el)}
            dangerouslySetInnerHTML={{ __html: sheet.htmlContent }}
            style={{
              display: 'inline-block',
              padding: '10px',
              border: '1px solid #ccc'
            }}
          />
        </div>
      ))}
      
      <button onClick={handleConvertToJsonl} disabled={loading}>
        {loading ? '변환 중...' : 'JSONL로 변환'}
      </button>
    </div>
  );
}

export default ExcelToJsonlConverter;
```

## 9. 트러블슈팅

### 문제: 이미지가 비어있거나 잘못 변환됨
**해결책:**
- 테이블 요소가 DOM에 실제로 렌더링되어 있는지 확인
- `display: none`이 아닌지 확인
- `scale` 값을 조정 (너무 크면 메모리 문제 발생 가능)

### 문제: 외부 이미지가 표시되지 않음
**해결책:**
```javascript
const canvas = await html2canvas(element, {
  useCORS: true,
  allowTaint: true,
  // 또는 외부 이미지를 base64로 변환해서 사용
});
```

### 문제: 큰 테이블에서 메모리 부족
**해결책:**
```javascript
const canvas = await html2canvas(element, {
  scale: 1, // scale을 낮춤
  width: 1920, // 최대 너비 제한
  height: 1080, // 최대 높이 제한
});
```

## 10. 요약

1. **html2canvas 설치**: `npm install html2canvas`
2. **테이블 요소 참조**: `useRef` 또는 `querySelector` 사용
3. **이미지 변환**: `html2canvas(element)` 호출
4. **base64 추출**: `canvas.toDataURL('image/png').split(',')[1]`
5. **API 호출**: `imageBase64`를 포함해서 요청 전송

이렇게 하면 프론트엔드에서 HTML 테이블을 이미지로 변환해서 JSONL에 포함시킬 수 있습니다!
