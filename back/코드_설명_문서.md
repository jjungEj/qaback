## 1. 프로젝트 개요

### 1.1 프로젝트 목적
QA(품질 보증) 파일 관리 시스템으로, 엑셀 파일(.xlsx, .xls, .csv) 및 HTML 파일을 업로드하고, 이를 HTML 형식으로 변환하여 저장·관리하는 백엔드 시스템입니다.

### 1.2 기술 스택
- **Framework**: Spring Boot 2.7.18
- **Java Version**: 8
- **ORM**: Spring Data JPA (Hibernate)
- **Database**: H2 (개발용 인메모리 DB)
- **Build Tool**: Maven
- **주요 라이브러리**:
  - Apache POI 5.2.3 (엑셀 파일 처리)
  - JSoup 1.17.2 (HTML 파싱)
  - Lombok (보일러플레이트 코드 제거)

### 1.3 주요 기능
- ✅ 엑셀/CSV 파일 업로드 및 HTML 변환
- ✅ HTML 파일 업로드 및 파싱
- ✅ **다중 파일 동시 업로드** (2025.11.18 추가)
- ✅ **파일 목록 페이징 처리** (2025.11.18 추가)
- ✅ **파일명 검색 기능** (2025.11.18 추가)
- ✅ **중복 파일 체크 및 알림** (2025.11.18 추가)
- ✅ 파일 상세 조회
- ✅ 피드백 저장
- ✅ 시트 편집 및 저장
- ✅ HTML을 JSONL 형식으로 변환

## 2. 아키텍처 구조

### 2.1 계층 구조
```
┌─────────────────────────────────────┐
│         Controller Layer            │  ← HTTP 요청/응답 처리
│      (QaController.java)            │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│         Service Layer                │  ← 비즈니스 로직 처리
│    (QaFileInfoService.java)         │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│       Repository Layer               │  ← 데이터 접근 처리
│  (QaFileInfoRepository.java)        │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│         Database (H2)                │  ← 데이터 저장
└─────────────────────────────────────┘
```

### 2.2 데이터 흐름
```
1. 클라이언트 요청
   ↓
2. Controller: HTTP 요청 수신, 파라미터 검증
   ↓
3. Service: 비즈니스 로직 처리
   - 파일 변환 (ExcelToHtmlConverter, HtmlTableParser)
   - 중복 체크
   - 엔티티 ↔ DTO 변환
   ↓
4. Repository: 데이터베이스 CRUD 작업
   ↓
5. Service: 결과를 DTO로 변환
   ↓
6. Controller: HTTP 응답 반환
```

## 4. 주요 클래스 상세 설명

### 4.1 Domain (엔티티)

#### 4.1.1 QaFileInfo.java
**역할**: 업로드된 파일의 메타 정보를 저장하는 엔티티

**주요 필드**:
```java
- Long id                    // 기본 키 (자동 증가)
- String fileName            // 파일명 (NOT NULL, 최대 255자)
- Long fileSize              // 파일 크기 (바이트 단위, NOT NULL)
- String fileType            // 파일 타입 (xlsx, xls, csv, html, NOT NULL)
- String feedback            // 확인 사항/피드백 (최대 1000자)
- List<QaFileSheet> sheets   // 시트 목록 (1:N 관계)
- LocalDateTime uploadedAt   // 업로드 시간 (자동 생성)
- LocalDateTime updatedAt    // 수정 시간 (자동 업데이트)
```

**특징**:
- `@OneToMany` 관계로 `QaFileSheet`와 연결
- `cascade = CascadeType.ALL, orphanRemoval = true` 설정으로 파일 삭제 시 연관된 시트도 자동 삭제
- `@OrderBy("sheetOrder ASC")`로 시트가 순서대로 정렬됨

#### 4.1.2 QaFileSheet.java
**역할**: 파일의 각 시트(Sheet) 정보를 저장하는 엔티티

**주요 필드**:
```java
- Long id                    // 기본 키 (자동 증가)
- String sheetName           // 시트명 (NOT NULL, 최대 255자)
- Integer sheetOrder          // 시트 순서 (NOT NULL)
- String htmlContent          // HTML 변환된 내용 (CLOB 타입, NOT NULL)
- QaFileInfo qaFileInfo       // 부모 파일 정보 (N:1 관계)
```

**특징**:
- `@ManyToOne(fetch = FetchType.LAZY)`로 지연 로딩 설정
- `@Lob` 어노테이션으로 대용량 텍스트 저장
- `qa_file_info_id` 외래 키로 `QaFileInfo`와 연결

### 4.2 Controller

#### 4.2.1 QaController.java
**역할**: QA 파일 관리 관련 REST API 엔드포인트 제공

**주요 메서드**:

1. **단일 파일 업로드 (엑셀/CSV)**
   ```java
   POST /api/qa/upload
   ```
   - 엑셀 파일을 받아 HTML로 변환 후 DB 저장
   - 중복 파일 체크 포함
   - 중복 시 HTTP 409 (CONFLICT) 반환

2. **다중 파일 업로드** (신규)
   ```java
   POST /api/qa/upload/multiple
   ```
   - 여러 파일을 동시에 업로드
   - 각 파일의 성공/중복/오류를 분리하여 응답

3. **HTML 파일 업로드**
   ```java
   POST /api/qa/upload/html
   ```
   - HTML 파일을 파싱하여 DB 저장
   - 중복 파일 체크 포함

4. **파일 목록 조회 (전체)**
   ```java
   GET /api/qa/files
   ```
   - 모든 파일 목록 반환 (하위 호환성 유지)

5. **파일 목록 조회 (페이징)** (신규)
   ```java
   GET /api/qa/files/paged?page=0&size=10
   ```
   - 페이징된 파일 목록 반환
   - 기본 페이지 크기: 10개

6. **파일 검색** (신규)
   ```java
   GET /api/qa/files/search?keyword=검색어&page=0&size=10
   ```
   - 파일명으로 검색 (대소문자 무시, 부분 일치)
   - 페이징 지원

7. **파일 상세 조회**
   ```java
   GET /api/qa/files/{id}
   ```
   - 특정 파일의 상세 정보 및 시트 목록 반환

8. **피드백 저장**
   ```java
   PUT /api/qa/files/{id}/feedback
   ```
   - 파일에 피드백 저장

9. **시트 편집 저장**
   ```java
   PUT /api/qa/files/{id}/sheets
   ```
   - 편집된 시트의 HTML 내용 저장

10. **파일 삭제**
    ```java
    DELETE /api/qa/files/{id}
    ```
    - 파일 삭제 (연관된 시트도 자동 삭제)

11. **JSONL 변환**
    ```java
    POST /api/qa/convert/jsonl
    ```
    - HTML 내용을 JSONL 형식으로 변환하여 다운로드

### 4.3 Service

#### 4.3.1 QaFileInfoService.java
**역할**: 파일 관리 비즈니스 로직 처리

**주요 메서드**:

1. **uploadFile()**
   - 엑셀/CSV 파일 업로드 처리
   - 중복 파일 체크
   - `ExcelToHtmlConverter`를 사용하여 HTML 변환
   - DB 저장

2. **uploadHtmlFile()**
   - HTML 파일 업로드 처리
   - 중복 파일 체크
   - `HtmlTableParser`를 사용하여 HTML 파싱
   - DB 저장

3. **uploadMultipleFiles()** (신규)
   - 여러 파일을 순회하며 업로드 처리
   - 각 파일의 성공/중복/오류를 분리하여 수집
   - `MultiUploadResponse` 객체로 결과 반환

4. **getAllFiles()**
   - 전체 파일 목록 조회
   - 업로드 시간 내림차순 정렬

5. **getFilesWithPaging()** (신규)
   - 페이징된 파일 목록 조회
   - Spring Data의 `Pageable` 사용
   - `PageResponse` 객체로 반환

6. **searchFiles()** (신규)
   - 파일명으로 검색
   - 대소문자 무시, 부분 일치 검색
   - 페이징 지원

7. **getFileById()**
   - ID로 파일 상세 조회
   - 시트 정보 포함

8. **updateFeedback()**
   - 파일 피드백 업데이트

9. **updateSheets()**
   - 시트의 HTML 내용 업데이트

10. **deleteFile()**
    - 파일 삭제
    - Cascade 설정으로 연관된 시트도 자동 삭제

**헬퍼 메서드**:
- `persistFileWithSheets()`: 파일과 시트 정보를 DB에 저장
- `toResponse()`: 엔티티를 상세 응답 DTO로 변환 (시트 정보 포함)
- `toListResponse()`: 엔티티를 목록 응답 DTO로 변환 (시트 정보 제외)
- `toSheetResponse()`: 시트 엔티티를 DTO로 변환
- `resolveFileType()`: 파일명에서 확장자 추출

### 4.4 Repository

### 4.5 DTO (Data Transfer Object)

**주요 필드**:
```java

```

**내부 클래스**: `QaFileSheetResponse`
- 시트 정보를 담는 응답 DTO

#### 4.5.2 MultiUploadResponse.java (신규)
**역할**: 다중 파일 업로드 결과 응답 DTO

**주요 필드**:
```java
- List<QaFileInfoResponse> successFiles      // 성공한 파일 목록
- List<DuplicateFileInfo> duplicateFiles     // 중복된 파일 목록
- List<ErrorFileInfo> errorFiles            // 오류 발생 파일 목록
```

**내부 클래스**:
- `DuplicateFileInfo`: 중복 파일 정보 (fileName, message)
- `ErrorFileInfo`: 오류 파일 정보 (fileName, errorMessage)

#### 4.5.3 PageResponse.java (신규)
**역할**: 페이징된 응답 DTO

**주요 필드**:
```java
- List<T> content           // 현재 페이지의 데이터
- int page                  // 현재 페이지 번호 (0부터 시작)
- int size                  // 페이지 크기
- long totalElements        // 전체 데이터 개수
- int totalPages            // 전체 페이지 수
- boolean hasNext           // 다음 페이지 존재 여부
- boolean hasPrevious       // 이전 페이지 존재 여부
```

#### 4.5.4 FeedbackRequest.java
**역할**: 피드백 저장 요청 DTO

**주요 필드**:
```java

```

#### 4.5.5 HtmlUpdateRequest.java
**역할**: HTML 업데이트 요청 DTO (JSONL 변환용)

## 5. API 엔드포인트

### 5.1 파일 업로드

#### 단일 파일 업로드 (엑셀/CSV)
```
POST /api/qa/upload
Content-Type: multipart/form-data

파라미터:
- file: MultipartFile (xlsx, xls, csv)

응답:
- 201 Created: QaFileInfoResponse
- 409 Conflict: "이미 업로드한 파일입니다: {파일명}"
- 400 Bad Request: 잘못된 요청
```

#### 다중 파일 업로드 (신규)
```
POST /api/qa/upload/multiple
Content-Type: multipart/form-data

파라미터:
- files: MultipartFile[] (여러 파일)

응답:
- 201 Created: MultiUploadResponse
  {
    "successFiles": [...],
    "duplicateFiles": [...],
    "errorFiles": [...]
  }
```

#### HTML 파일 업로드
```
POST /api/qa/upload/html
Content-Type: multipart/form-data

파라미터:
- file: MultipartFile (html, htm)

응답:
- 201 Created: QaFileInfoResponse
- 409 Conflict: "이미 업로드한 파일입니다: {파일명}"
```

### 5.2 파일 조회

#### 전체 파일 목록
```
GET /api/qa/files

응답:
- 200 OK: List<QaFileInfoResponse>
```

#### 페이징된 파일 목록 (신규)
```
GET /api/qa/files/paged?page=0&size=10

파라미터:
- page: int (기본값: 0)
- size: int (기본값: 10)

응답:
- 200 OK: PageResponse<QaFileInfoResponse>
```

#### 파일 검색 (신규)
```
GET /api/qa/files/search?keyword=검색어&page=0&size=10

파라미터:
- keyword: String (필수)
- page: int (기본값: 0)
- size: int (기본값: 10)
```

## 7. 주요 기능 설명

### 7.1 파일 업로드 및 변환 프로세스

1. **엑셀 파일 업로드**
   ```
   클라이언트 → Controller → Service
   → ExcelToHtmlConverter.convertToHtml()
   → 각 시트를 HTML 테이블로 변환
   → QaFileInfo + QaFileSheet 엔티티 생성
   → Repository.save()
   → DB 저장 완료
   ```

2. **HTML 파일 업로드**
   ```
   클라이언트 → Controller → Service
   → HtmlTableParser.parse()
   → HTML에서 <table> 태그 추출
   → 각 테이블을 시트로 변환
   → QaFileInfo + QaFileSheet 엔티티 생성
   → Repository.save()
   → DB 저장 완료
   ```

### 7.2 중복 파일 체크 로직

```java
// 파일명으로 중복 체크
Optional<QaFileInfo> existing = repository.findByFileName(fileName);
if (existing.isPresent()) {
    throw new ResponseStatusException(HttpStatus.CONFLICT, "이미 업로드한 파일입니다: " + fileName);
}
```

**체크 시점**:
- 단일 파일 업로드: 업로드 전 체크
- 다중 파일 업로드: 각 파일별로 개별 체크

### 7.3 페이징 처리 로직

```java
// Spring Data JPA의 Pageable 사용
Pageable pageable = PageRequest.of(page, size);
Page<QaFileInfo> filePage = repository.findAllByOrderByUploadedAtDesc(pageable);

// PageResponse로 변환
return new PageResponse<>(
    content,           // 현재 페이지 데이터
    page,             // 현재 페이지 번호
    size,             // 페이지 크기
    filePage.getTotalElements()  // 전체 개수
);
```

**페이징 정보 계산**:
- `totalPages = ceil(totalElements / size)`
- `hasNext = page < totalPages - 1`
- `hasPrevious = page > 0`

### 7.4 검색 기능 로직

```java
// 파일명 부분 일치 검색 (대소문자 무시)
Page<QaFileInfo> filePage = repository
    .findByFileNameContainingIgnoreCaseOrderByUploadedAtDesc(keyword, pageable);
```

**검색 특징**:
- 부분 일치: 파일명에 검색어가 포함되면 매칭
- 대소문자 무시: "TEST"와 "test" 동일하게 처리
- 페이징 지원: 검색 결과도 페이징 처리
