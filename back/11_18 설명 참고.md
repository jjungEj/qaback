# 11/18 설명 참고

## 📋 시스템 흐름도

### 1. 엑셀 파일 업로드 및 변환 흐름
```
[프론트엔드]
    ↓ (MultipartFile 업로드)
[QaController.uploadExcel()]
    ↓
[QaFileInfoService.uploadFile()]
    ↓
[ExcelToHtmlConverter.convertToHtml()]
    ├─ xlsx/xls → Apache POI로 파싱
    └─ csv → BufferedReader로 파싱
    ↓
[HTML 테이블 생성]
    ↓
[QaFileInfo + QaFileSheet 엔티티 생성]
    ↓
[QaFileInfoRepository.save()]
    ↓
[DB 저장 완료]
```

### 2. 파일 조회 흐름
```
[프론트엔드]
    ↓ (GET /api/qa/files 또는 /api/qa/files/{id})
[QaController.getFileList() / getFileDetail()]
    ↓
[QaFileInfoService.getAllFiles() / getFileById()]
    ↓
[QaFileInfoRepository 조회]
    ↓
[QaFileInfoResponse DTO 변환]
    ↓
[JSON 응답 반환]
```

### 3. 피드백 저장 흐름
```
[프론트엔드]
    ↓ (PUT /api/qa/files/{id}/feedback)
[QaController.updateFeedback()]
    ↓
[QaFileInfoService.updateFeedback()]
    ↓
[QaFileInfo 엔티티 조회 및 피드백 필드 업데이트]
    ↓
[QaFileInfoRepository.save()]
    ↓
[DB 저장 완료]
```

### 4. 시트 편집 저장 흐름
```
[프론트엔드]
    ↓ (PUT /api/qa/files/{id}/sheets)
[QaController.updateSheets()]
    ↓
[QaFileInfoService.updateSheets()]
    ↓
[QaFileInfo 엔티티 조회]
    ↓
[각 시트의 HTML 내용 업데이트]
    ↓
[QaFileInfoRepository.save()]
    ↓
[DB 저장 완료]
```

### 5. JSONL 변환 흐름
```
[프론트엔드]
    ↓ (POST /api/qa/convert/jsonl)
[QaController.convertToJsonl()]
    ↓
[HtmlUpdateRequest에서 시트 데이터 추출]
    ↓
[JsonlConverter.toJsonlBytes()]
    ├─ 각 시트를 JSONL 한 줄로 변환
    └─ HTML과 이미지(base64) 포함
    ↓
[ByteArrayResource로 파일 다운로드 제공]
```

## 🚀 추가로 만들면 좋은 것들

### 1. 예외 처리 (Exception Handling)
- **GlobalExceptionHandler** 클래스 생성
  - `@ControllerAdvice`를 사용한 전역 예외 처리
  - 파일 업로드 실패, 파일 형식 오류, DB 오류 등 처리
  - 일관된 에러 응답 형식 제공

```java
@ControllerAdvice
public class GlobalExceptionHandler {
    @ExceptionHandler(IllegalArgumentException.class)
    public ResponseEntity<ErrorResponse> handleIllegalArgument(...) { }
    
    @ExceptionHandler(IOException.class)
    public ResponseEntity<ErrorResponse> handleIOException(...) { }
}
```

### 2. 로깅 (Logging)
- **SLF4J + Logback** 사용
  - 각 주요 메서드에 로깅 추가
  - 파일 업로드, 변환, 저장 시 로그 기록
  - 에러 발생 시 상세 로그 기록

```java
private static final Logger log = LoggerFactory.getLogger(QaFileInfoService.class);

public QaFileInfoResponse uploadFile(...) {
```

## 📝 개발 시 주의사항

### 1. 트랜잭션 관리
- `@Transactional` 어노테이션 적절히 사용
- 읽기 전용 메서드는 `@Transactional(readOnly = true)` 사용

### 2. 메모리 관리
- 대용량 파일 처리 시 스트리밍 방식 고려
- Workbook 사용 후 반드시 `close()` 호출 (현재 코드에 이미 구현됨)

### 3. 데이터베이스 설계
- 현재는 HTML을 CLOB로 저장 중
- 대용량 HTML의 경우 파일 시스템 저장 고려

### 4. 코드 구조
- Controller는 요청/응답 처리만 담당
- 비즈니스 로직은 Service에 구현
- 유틸리티는 재사용 가능하도록 설계

### 5. 에러 메시지
- 사용자 친화적인 에러 메시지 제공
- 개발자를 위한 상세 에러 로그 기록
