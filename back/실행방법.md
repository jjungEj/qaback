# Spring Boot 애플리케이션 실행 방법

## 1. 필수 요구사항
- **Java**: JDK 8 이상 (권장: JDK 11~17)
- **Maven**: 3.6 이상
- **포트**: 8080 (기본값, application.yml에서 변경 가능)

## 2. 실행 방법

### 방법 1: Maven으로 직접 실행 (가장 간단)

```bash
# 프로젝트 루트 디렉토리에서 실행
mvn spring-boot:run
```

**PowerShell에서 실행:**
```powershell
cd c:\qa\qaback\back
mvn spring-boot:run
```

### 방법 2: 빌드 후 JAR 파일 실행

```bash
# 1. 빌드
mvn clean package

# 2. JAR 파일 실행
java -jar target/stereotypesdb-0.0.1-SNAPSHOT.jar
```

### 방법 3: IDE에서 실행 (IntelliJ IDEA / Eclipse)

**IntelliJ IDEA:**
1. 프로젝트 열기
2. `src/main/java/vaatz/stereotypesdb/qa/QaApplication.java` 파일 찾기
3. 메인 클래스 우클릭 → `Run 'QaApplication'`

**Eclipse:**
1. 프로젝트 우클릭 → `Run As` → `Spring Boot App`

## 3. 실행 확인

애플리케이션이 정상적으로 실행되면 다음과 같은 메시지가 표시됩니다:

```
Started Application in X.XXX seconds
```

그리고 브라우저나 API 클라이언트에서 다음 URL로 접근 가능합니다:

- **API Base URL**: `http://localhost:8080/api/qa`
- **H2 콘솔**: `http://localhost:8080/h2-console`

## 4. API 테스트

### 파일 목록 조회
```bash
curl http://localhost:8080/api/qa/files
```

### 파일 업로드
```bash
curl -X POST http://localhost:8080/api/qa/upload \
  -F "file=@example.xlsx"
```

## 5. H2 데이터베이스 콘솔 접속

1. 브라우저에서 `http://localhost:8080/h2-console` 접속
2. 연결 정보 입력:
   - **JDBC URL**: `jdbc:h2:mem:testdb`
   - **User Name**: `sa`
   - **Password**: (비워두기)
3. `Connect` 클릭

## 6. 문제 해결

### 포트가 이미 사용 중인 경우
```yaml
# application.yml 수정
server:
  port: 8081  # 다른 포트로 변경
```

### Maven이 설치되지 않은 경우
- Maven 설치: https://maven.apache.org/download.cgi
- 또는 IDE의 내장 Maven 사용

### Java 버전 문제
```bash
# Java 버전 확인
java -version

# JAVA_HOME 환경변수 설정 필요
```

## 7. 개발 모드 팁

- **자동 재시작**: 코드 수정 후 저장하면 자동으로 재시작됩니다 (Spring Boot DevTools)
- **로그 확인**: 콘솔에서 SQL 쿼리와 에러 메시지 확인 가능
- **H2 메모리 DB**: 애플리케이션 종료 시 데이터가 사라집니다 (개발용)
