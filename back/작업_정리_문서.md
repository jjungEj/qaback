## ⚠️ 오류 사항 및 해결 방안

### 오류 1: ClassNotFoundException - QaApplication

**증상:**
```
Error: Could not find or load main class vaatz.stereotypesdb.qa.QaApplication
Caused by: java.lang.ClassNotFoundException: vaatz.stereotypesdb.qa.QaApplication
```

**원인:**
- Spring Boot 메인 클래스가 없었음
- IDE에서 프로젝트를 Maven 프로젝트로 인식하지 못함

**해결 방안:**
1. `QaApplication.java` 메인 클래스 생성
2. IDE에서 Maven 프로젝트로 인식시키기
   - IntelliJ: Maven 탭 → Reload Project
   - Eclipse: Configure → Convert to Maven Project
3. 프로젝트 빌드
   - `Build → Rebuild Project`

---

### 오류 2: JSONL에서 image 필드가 빈 문자열

**증상:**
```json
{"image":"","html":"<table>...</table>"}
```

**원인:**
- 프론트엔드에서 `imageBase64`를 전달하지 않음
- 백엔드에서 HTML을 이미지로 자동 변환하는 기능 없음

**해결 방안:**
1. `HtmlUpdateRequest`에 `imageBase64` 필드 추가
2. 프론트엔드에서 `html2canvas` 라이브러리로 HTML 테이블을 이미지로 변환
3. 변환된 이미지를 base64로 인코딩하여 전송

**프론트엔드 구현 필요:**
```javascript
import html2canvas from 'html2canvas';

const canvas = await html2canvas(tableElement);
const base64String = canvas.toDataURL('image/png').split(',')[1];
```

---

### 오류 3: IDE 린터 오류 - QaFileSheet cannot be resolved

**증상:**
```
QaFileSheet cannot be resolved to a type
```

**원인:**
- IDE 캐시 문제
- 같은 패키지에 있어서 import 불필요하지만 IDE가 인식 못함

**해결 방안:**
- 프로젝트 재빌드
- IDE 재시작
- 실제 컴파일 오류는 아님 (런타임 정상 동작)

---

### 오류 4: DTO 중복 - FileInfoResponse vs FileInfoListResponse

**증상:**
- 거의 동일한 DTO가 두 개 존재
- 유지보수 복잡도 증가

**해결 방안:**
- `FileInfoListResponse` 삭제
- `QaFileInfoResponse` 하나로 통합
- 목록 조회 시 `sheets` 필드를 `null`로 설정

## 💬 코드 주석 가이드

### 1. Controller 주석

#### QaController.java

```java
/**
 * QA 파일 관리 및 변환 컨트롤러
 * 
 * 주요 기능:
 * - 엑셀 파일 업로드 및 HTML 변환
 * - 파일 목록/상세 조회
 * - 피드백 저장
 * - HTML → JSONL 변환
 * 
 * @author 개발자명
 * @since 2024
 */
@RestController
@RequestMapping("/api/qa")
public class QaController {
    
    /**
     * 엑셀 파일 업로드 및 HTML 변환 (DB 저장)
     * 
     * 지원 형식: xlsx, xls, csv
     * 처리 과정:
     * 1. 파일 유효성 검사
     * 2. 엑셀 → HTML 변환 (ExcelToHtmlConverter)
     * 3. 파일 정보 및 시트 정보 DB 저장
     * 4. 변환된 HTML 반환
     * 
     * @param file 업로드할 엑셀 파일
     * @return QaFileInfoResponse 파일 정보 및 변환된 HTML
     * @throws IOException 파일 읽기 오류
     */
    @PostMapping(value = "/upload", consumes = MediaType.MULTIPART_FORM_DATA_VALUE)
    public ResponseEntity<QaFileInfoResponse> uploadExcel(@RequestPart("file") MultipartFile file) {
        // 파일이 비어있는지 확인
        if (file.isEmpty()) {
            return ResponseEntity.badRequest().build();
        }

        String fileName = file.getOriginalFilename();
        // 지원하는 파일 형식인지 확인 (xlsx, xls, csv)
        if (fileName == null || (!fileName.toLowerCase().endsWith(".xlsx") 
                && !fileName.toLowerCase().endsWith(".xls") 
                && !fileName.toLowerCase().endsWith(".csv"))) {
            return ResponseEntity.badRequest().build();
        }

        try {
            // 파일 확장자 추출 (xlsx, xls, csv)
            String fileType = fileName.substring(fileName.lastIndexOf('.') + 1).toLowerCase();
            
            // 서비스 레이어에서 파일 업로드 및 변환 처리
            QaFileInfoResponse response = qaFileInfoService.uploadFile(
                    fileName, file.getSize(), fileType, file.getInputStream());
            
            // 201 Created 상태로 응답
            return ResponseEntity.status(HttpStatus.CREATED).body(response);
        } catch (IOException e) {
            // 파일 읽기 오류 시 500 에러 반환
            return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR).build();
        }
    }

    /**
     * 파일 목록 조회
     * 
     * 업로드된 모든 파일을 최신순으로 조회합니다.
     * 목록 조회이므로 시트 정보(sheets)는 포함하지 않습니다.
     * 
     * @return 파일 목록 (업로드 시간 내림차순)
     */
    @GetMapping("/files")
    public ResponseEntity<List<QaFileInfoResponse>> getFileList() {
        return ResponseEntity.ok(qaFileInfoService.getAllFiles());
    }

    /**
     * 파일 상세 조회
     * 
     * 특정 파일의 상세 정보와 모든 시트의 HTML 내용을 조회합니다.
     * 
     * @param id 파일 ID
     * @return 파일 상세 정보 (시트 HTML 포함)
     */
    @GetMapping("/files/{id}")
    public ResponseEntity<QaFileInfoResponse> getFileDetail(@PathVariable Long id) {
        return ResponseEntity.ok(qaFileInfoService.getFileById(id));
    }

    /**
     * 피드백 저장
     * 
     * 파일의 확인 사항(피드백)을 저장합니다.
     * 피드백은 한 줄 정도의 간단한 메모로 사용됩니다.
     * 
     * @param id 파일 ID
     * @param request 피드백 내용
     * @return 업데이트된 파일 정보
     */
    @PutMapping("/files/{id}/feedback")
    public ResponseEntity<QaFileInfoResponse> updateFeedback(
            @PathVariable Long id,
            @Valid @RequestBody FeedbackRequest request) {
        return ResponseEntity.ok(qaFileInfoService.updateFeedback(id, request));
    }

    /**
     * 수정된 HTML을 JSONL 형식으로 변환
     * 
     * 프론트엔드에서 수정한 HTML 테이블을 JSONL 형식으로 변환하여 다운로드합니다.
     * 
     * 처리 과정:
     * 1. 프론트엔드에서 전달한 HTML과 base64 이미지 받기
     * 2. 각 시트를 JSONL 한 줄씩 변환
     *    형식: {"image": "base64_string", "html": "<table>...</table>"}
     * 3. 여러 시트가 있으면 각각 한 줄씩 (\n으로 구분)
     * 4. 파일로 다운로드
     * 
     * 주의사항:
     * - imageBase64는 프론트엔드에서 html2canvas로 생성해야 함
     * - imageBase64가 없으면 빈 문자열로 저장됨
     * 
     * @param request HTML 수정 요청 (시트별 HTML과 이미지)
     * @return JSONL 파일 (바이너리)
     */
    @PostMapping("/convert/jsonl")
    public ResponseEntity<ByteArrayResource> convertToJsonl(@Valid @RequestBody HtmlUpdateRequest request) {
        try {
            // 요청 데이터를 SheetData로 변환
            List<ExcelToHtmlConverter.SheetData> sheets = request.getSheets().stream()
                    .map(sheet -> new ExcelToHtmlConverter.SheetData(
                            sheet.getSheetName(), 
                            sheet.getHtmlContent(), 
                            sheet.getImageBase64())) // 프론트엔드에서 전달한 base64 이미지 사용
                    .collect(Collectors.toList());

            // JSONL 형식으로 변환
            byte[] jsonlBytes = JsonlConverter.toJsonlBytes(sheets);
            ByteArrayResource resource = new ByteArrayResource(jsonlBytes);
            
            // 파일명 생성 (원본 파일명의 확장자를 .jsonl로 변경)
            String jsonlFileName = request.getFileName();
            if (jsonlFileName != null && jsonlFileName.contains(".")) {
                jsonlFileName = jsonlFileName.substring(0, jsonlFileName.lastIndexOf('.')) + ".jsonl";
            } else {
                jsonlFileName = "output.jsonl";
            }

            // 파일 다운로드 응답
            return ResponseEntity.ok()
                    .contentType(MediaType.APPLICATION_OCTET_STREAM)
                    .header(HttpHeaders.CONTENT_DISPOSITION, "attachment; filename=\"" + jsonlFileName + "\"")
                    .contentLength(jsonlBytes.length)
                    .body(resource);
        } catch (Exception e) {
            // 변환 오류 시 500 에러 반환
            return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR).build();
        }
    }
}
```

```java
/**
 * QA 파일 정보 관리 서비스
 * 
 * 주요 책임:
 * - 파일 업로드 및 HTML 변환 처리
 * - 파일 정보 CRUD
 * - 엔티티 ↔ DTO 변환
 * 
 * 트랜잭션:
 * - 모든 메서드는 @Transactional로 트랜잭션 관리
 * - 예외 발생 시 자동 롤백
 */
@Service
@Transactional
public class QaFileInfoService {

    /**
     * 파일 업로드 및 HTML 변환
     * 
     * 처리 과정:
     * 1. ExcelToHtmlConverter로 엑셀을 HTML로 변환
     * 2. QaFileInfo 엔티티 생성 및 파일 정보 저장
     * 3. 각 시트를 QaFileSheet 엔티티로 변환하여 저장
     * 4. Cascade로 시트도 함께 저장됨
     * 
     * @param fileName 파일명 (확장자 포함)
     * @param fileSize 파일 크기 (바이트)
     * @param fileType 파일 타입 (xlsx, xls, csv)
     * @param inputStream 파일 입력 스트림
     * @return 변환된 파일 정보 응답
     * @throws IOException 파일 읽기 오류
     */
    public QaFileInfoResponse uploadFile(String fileName, long fileSize, String fileType, 
                                       java.io.InputStream inputStream) throws IOException {
        // 엑셀을 HTML로 변환 (ExcelToHtmlConverter 사용)
        List<ExcelToHtmlConverter.SheetData> sheets = ExcelToHtmlConverter.convertToHtml(inputStream, fileName);

        // QaFileInfo 엔티티 생성
        QaFileInfo qaFileInfo = new QaFileInfo();
        qaFileInfo.setFileName(fileName);
        qaFileInfo.setFileSize(fileSize);
        qaFileInfo.setFileType(fileType);

        // 시트 정보 저장
        int order = 0;
        for (ExcelToHtmlConverter.SheetData sheetData : sheets) {
            QaFileSheet qaFileSheet = new QaFileSheet();
            qaFileSheet.setSheetName(sheetData.getSheetName());
            qaFileSheet.setSheetOrder(order++); // 시트 순서 (0부터 시작)
            qaFileSheet.setHtmlContent(sheetData.getHtmlContent());
            qaFileSheet.setQaFileInfo(qaFileInfo); // 양방향 관계 설정
            qaFileInfo.getSheets().add(qaFileSheet);
        }

        // DB 저장 (Cascade로 시트도 함께 저장됨)
        QaFileInfo saved = qaFileInfoRepository.save(qaFileInfo);
        return toResponse(saved);
    }

    /**
     * 파일 목록 조회
     * 
     * 업로드 시간 내림차순으로 정렬하여 반환합니다.
     * 목록 조회이므로 시트 정보는 포함하지 않습니다 (sheets = null).
     * 
     * @return 파일 목록 (최신순)
     */
    public List<QaFileInfoResponse> getAllFiles() {
        List<QaFileInfo> files = qaFileInfoRepository.findAllByOrderByUploadedAtDesc();
        return files.stream()
                .map(this::toListResponse) // 엔티티 → DTO 변환
                .collect(Collectors.toList());
    }

    /**
     * 파일 상세 조회
     * 
     * 파일 ID로 파일 정보와 모든 시트의 HTML 내용을 조회합니다.
     * 
     * @param id 파일 ID
     * @return 파일 상세 정보 (시트 HTML 포함)
     * @throws ResponseStatusException 파일을 찾을 수 없을 경우 404 에러
     */
    public QaFileInfoResponse getFileById(Long id) {
        QaFileInfo qaFileInfo = qaFileInfoRepository.findById(id)
                .orElseThrow(() -> new ResponseStatusException(HttpStatus.NOT_FOUND, "파일을 찾을 수 없습니다."));
        return toResponse(qaFileInfo);
    }

    /**
     * 피드백 저장
     * 
     * 파일의 확인 사항(피드백)을 업데이트합니다.
     * 피드백은 한 줄 정도의 간단한 메모로 사용됩니다.
     * 
     * @param id 파일 ID
     * @param request 피드백 요청 (feedback 필드 포함)
     * @return 업데이트된 파일 정보
     * @throws ResponseStatusException 파일을 찾을 수 없을 경우 404 에러
     */
    public QaFileInfoResponse updateFeedback(Long id, FeedbackRequest request) {
        QaFileInfo qaFileInfo = qaFileInfoRepository.findById(id)
                .orElseThrow(() -> new ResponseStatusException(HttpStatus.NOT_FOUND, "파일을 찾을 수 없습니다."));
        qaFileInfo.setFeedback(request.getFeedback());
        QaFileInfo saved = qaFileInfoRepository.save(qaFileInfo);
        return toResponse(saved);
    }

    /**
     * 엔티티 → DTO 변환 (상세 조회용)
     * 
     * 모든 필드와 시트 정보를 포함하여 변환합니다.
     * 
     * @param qaFileInfo 파일 정보 엔티티
     * @return 파일 정보 응답 DTO
     */
    private QaFileInfoResponse toResponse(QaFileInfo qaFileInfo) {
        QaFileInfoResponse response = new QaFileInfoResponse();
        response.setId(qaFileInfo.getId());
        response.setFileName(qaFileInfo.getFileName());
        response.setFileSize(qaFileInfo.getFileSize());
        response.setFileType(qaFileInfo.getFileType());
        response.setFeedback(qaFileInfo.getFeedback());
        response.setUploadedAt(qaFileInfo.getUploadedAt());
        response.setUpdatedAt(qaFileInfo.getUpdatedAt());
        // 시트 정보 포함 (상세 조회용)
        response.setSheets(qaFileInfo.getSheets().stream()
                .map(this::toSheetResponse)
                .collect(Collectors.toList()));
        return response;
    }

    /**
     * 엔티티 → DTO 변환 (목록 조회용)
     * 
     * 시트 정보는 제외하고 기본 정보만 변환합니다.
     * 목록 조회 시 성능 최적화를 위해 시트 정보를 로드하지 않습니다.
     * 
     * @param qaFileInfo 파일 정보 엔티티
     * @return 파일 정보 응답 DTO (sheets = null)
     */
    private QaFileInfoResponse toListResponse(QaFileInfo qaFileInfo) {
        QaFileInfoResponse response = new QaFileInfoResponse();
        response.setId(qaFileInfo.getId());
        response.setFileName(qaFileInfo.getFileName());
        response.setFileSize(qaFileInfo.getFileSize());
        response.setFileType(qaFileInfo.getFileType());
        response.setFeedback(qaFileInfo.getFeedback());
        response.setUploadedAt(qaFileInfo.getUploadedAt());
        response.setUpdatedAt(qaFileInfo.getUpdatedAt());
        // 목록 조회 시에는 sheets 정보 제외 (null 또는 빈 리스트)
        // 성능 최적화: 시트 정보는 상세 조회에서만 로드
        response.setSheets(null);
        return response;
    }

    /**
     * 시트 엔티티 → 시트 DTO 변환
     * 
     * @param sheet 시트 엔티티
     * @return 시트 응답 DTO
     */
    private QaFileInfoResponse.QaFileSheetResponse toSheetResponse(QaFileSheet sheet) {
        QaFileInfoResponse.QaFileSheetResponse response = new QaFileInfoResponse.QaFileSheetResponse();
        response.setId(sheet.getId());
        response.setSheetName(sheet.getSheetName());
        response.setSheetOrder(sheet.getSheetOrder());
        response.setHtmlContent(sheet.getHtmlContent());
        return response;
    }
}
```

```java
/**

 *

 * 관계:
 * - QaFileSheet와 1:N 관계 (Cascade.ALL, orphanRemoval = true)
 *   → 파일 삭제 시 시트도 함께 삭제됨

 * 자동 생성 필드:
 * - uploadedAt: 파일 업로드 시간 (생성 시 자동 설정)

@Getter
@Setter
@Entity
@Table(name = "qa_file_info")
public class QaFileInfo {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    /**
     * 파일명 (확장자 포함)

    @Column(nullable = false, length = 255)
    private String fileName;

     * 파일 크기 (바이트 단위)
     * 예: 12345 (12.3 KB)
     */
    @Column(nullable = false)
    private Long fileSize;

    /**
     * 파일 타입
     * 값: "xlsx", "xls", "csv"
     */
    @Column(nullable = false, length = 10)
    private String fileType; // xlsx, xls, csv

    /**
     * 확인 사항/피드백
     * 사용자가 입력한 한 줄 정도의 메모
     * 예: "병합 셀 확인 필요", "3행 2열 부분 수정 완료"
     */
    @Column(length = 1000)
    private String feedback; // 확인 사항/피드백

    /**
     * 시트 목록
     * 
     * 관계 설정:
     * - mappedBy: QaFileSheet의 qaFileInfo 필드와 매핑

    @OneToMany(mappedBy = "qaFileInfo", cascade = CascadeType.ALL, orphanRemoval = true)

    /**
     * 파일 업로드 시간

    @CreationTimestamp
    private LocalDateTime uploadedAt;

    /**
     * 파일 수정 시간
     * @UpdateTimestamp로 자동 업데이트됨
     */
    @UpdateTimestamp
    private LocalDateTime updatedAt;
```

```java
/**
 * 엑셀 파일을 HTML 테이블로 변환하는 유틸리티
 * 
 * 지원 형식:
 * - xlsx (Excel 2007+)
 * - xls (Excel 97-2003)
 * - csv (쉼표로 구분된 값)
 * 
 * 주요 기능:
 * - 엑셀 시트를 HTML <table> 태그로 변환
 * - 병합 셀(rowspan, colspan) 지원
 * - 여러 시트 처리
 * 
 * 사용 라이브러리:
 * - Apache POI (엑셀 파일 읽기)
 */
public class ExcelToHtmlConverter {

    /**
     * 시트 데이터를 담는 내부 클래스
     * 
     * 변환된 시트 정보를 담는 데이터 클래스
     */
    public static class SheetData {
        private String sheetName;      // 시트명
        private String htmlContent;    // HTML 테이블 내용
        private String imageBase64;     // 이미지 base64 (현재는 null, 프론트엔드에서 생성)

        public SheetData(String sheetName, String htmlContent, String imageBase64) {
            this.sheetName = sheetName;
            this.htmlContent = htmlContent;
            this.imageBase64 = imageBase64;
        }

        // Getters...
    }

    /**
     * 엑셀 파일을 HTML로 변환
     * 
     * 파일 확장자에 따라 적절한 변환 메서드를 호출합니다.
     * 
     * @param inputStream 파일 입력 스트림
     * @param fileName 파일명 (확장자 포함)
     * @return 시트별 HTML 데이터 리스트
     * @throws IOException 파일 읽기 오류
     * @throws IllegalArgumentException 지원하지 않는 파일 형식
     */
    public static List<SheetData> convertToHtml(InputStream inputStream, String fileName) throws IOException {
        String lowerFileName = fileName.toLowerCase();
        
        // CSV 파일 처리
        if (lowerFileName.endsWith(".csv")) {
            return convertCsvToHtml(inputStream, fileName);
        } 
        // Excel 2007+ (xlsx) 처리
        else if (lowerFileName.endsWith(".xlsx")) {
            return convertExcelToHtml(inputStream, true);
        } 
        // Excel 97-2003 (xls) 처리
        else if (lowerFileName.endsWith(".xls")) {
            return convertExcelToHtml(inputStream, false);
        } 
        // 지원하지 않는 형식
        else {
            throw new IllegalArgumentException("지원하지 않는 파일 형식입니다. xlsx, xls, csv 파일만 지원합니다.");
        }
    }

    /**
     * 엑셀 파일(xlsx, xls)을 HTML로 변환
     * 
     * Apache POI를 사용하여 엑셀 파일을 읽고 HTML로 변환합니다.
     * 
     * @param inputStream 파일 입력 스트림
     * @param isXlsx true면 xlsx, false면 xls
     * @return 시트별 HTML 데이터 리스트
     * @throws IOException 파일 읽기 오류
     */
    private static List<SheetData> convertExcelToHtml(InputStream inputStream, boolean isXlsx) throws IOException {
        Workbook workbook;
        
        // 파일 형식에 따라 적절한 Workbook 생성
        if (isXlsx) {
            workbook = new XSSFWorkbook(inputStream); // Excel 2007+
        } else {
            workbook = new HSSFWorkbook(inputStream); // Excel 97-2003
        }

        List<SheetData> sheets = new ArrayList<>();
        
        try {
            // 모든 시트를 순회하며 HTML로 변환
            for (int i = 0; i < workbook.getNumberOfSheets(); i++) {
                Sheet sheet = workbook.getSheetAt(i);
                String sheetName = sheet.getSheetName();
                String htmlContent = convertSheetToHtml(sheet); // 시트를 HTML로 변환
                sheets.add(new SheetData(sheetName, htmlContent, null)); // 이미지는 null (프론트엔드에서 생성)
            }
        } finally {
            // 리소스 해제 (메모리 누수 방지)
            workbook.close();
        }

        return sheets;
    }

    /**
     * CSV 파일을 HTML로 변환
     * 
     * CSV 파일을 읽어서 HTML 테이블로 변환합니다.
     * 
     * 처리 과정:
     * 1. 파일을 UTF-8로 읽기
     * 2. 각 줄을 파싱하여 셀로 분리
     * 3. HTML <table> 태그로 변환
     * 
     * @param inputStream 파일 입력 스트림
     * @param fileName 파일명 (시트명으로 사용)
     * @return 시트별 HTML 데이터 리스트 (CSV는 시트 1개)
     * @throws IOException 파일 읽기 오류
     */
    private static List<SheetData> convertCsvToHtml(InputStream inputStream, String fileName) throws IOException {
        List<SheetData> sheets = new ArrayList<>();
        // 파일명에서 확장자 제거하여 시트명으로 사용
        String sheetName = fileName.substring(0, fileName.lastIndexOf('.'));
        
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(inputStream, StandardCharsets.UTF_8))) {
            
            StringBuilder html = new StringBuilder();
            html.append("<table border='1' cellpadding='5' cellspacing='0' style='border-collapse: collapse;'>\n");
            
            String line;
            // 각 줄을 읽어서 테이블 행으로 변환
            while ((line = reader.readLine()) != null) {
                html.append("<tr>\n");
                String[] cells = parseCsvLine(line); // CSV 줄 파싱
                for (String cell : cells) {
                    html.append("<td>").append(escapeHtml(cell)).append("</td>\n");
                }
                html.append("</tr>\n");
            }
            
            html.append("</table>");
            sheets.add(new SheetData(sheetName, html.toString(), null));
        }
        
        return sheets;
    }

    /**
     * CSV 줄을 파싱하여 셀 배열로 변환
     * 
     * 따옴표로 감싸진 값과 쉼표를 올바르게 처리합니다.
     * 
     * 예시:
     * - "value1,value2" → ["value1,value2"] (쉼표가 값 안에 있음)
     * - value1,value2 → ["value1", "value2"]
     * 
     * @param line CSV 한 줄
     * @return 셀 배열
     */
    private static String[] parseCsvLine(String line) {
        List<String> cells = new ArrayList<>();
        boolean inQuotes = false;
        StringBuilder currentCell = new StringBuilder();
        
        for (int i = 0; i < line.length(); i++) {
            char c = line.charAt(i);
            
            if (c == '"') {
                // 이스케이프된 따옴표 처리 ("")
                if (inQuotes && i + 1 < line.length() && line.charAt(i + 1) == '"') {
                    currentCell.append('"');
                    i++;
                } else {
                    // 따옴표 시작/끝 토글
                    inQuotes = !inQuotes;
                }
            } else if (c == ',' && !inQuotes) {
                // 셀 구분자 (따옴표 밖의 쉼표)
                cells.add(currentCell.toString());
                currentCell = new StringBuilder();
            } else {
                currentCell.append(c);
            }
        }
        
        // 마지막 셀 추가
        cells.add(currentCell.toString());
        
        return cells.toArray(new String[0]);
    }

    /**
     * 엑셀 시트를 HTML 테이블로 변환
     * 
     * 처리 과정:
     * 1. 병합 셀 정보 수집
     * 2. 각 행을 순회하며 HTML <tr> 태그 생성
     * 3. 병합 셀은 rowspan, colspan 속성 추가
     * 4. 셀 값 타입에 따라 적절히 변환 (문자열, 숫자, 날짜, 수식)
     * 
     * @param sheet 엑셀 시트
     * @return HTML 테이블 문자열
     */
    private static String convertSheetToHtml(Sheet sheet) {
        StringBuilder html = new StringBuilder();
        html.append("<table border='1' cellpadding='5' cellspacing='0' style='border-collapse: collapse;'>\n");

        int firstRowNum = sheet.getFirstRowNum();
        int lastRowNum = sheet.getLastRowNum();

        // 빈 시트 처리
        if (firstRowNum > lastRowNum) {
            html.append("</table>");
            return html.toString();
        }

        // 병합 셀 정보 수집
        List<CellRangeAddress> mergedRegions = sheet.getMergedRegions();

        // 각 행을 순회하며 HTML로 변환
        for (int rowNum = firstRowNum; rowNum <= lastRowNum; rowNum++) {
            Row row = sheet.getRow(rowNum);
            html.append("<tr>\n");

            // 빈 행 처리
            if (row == null) {
                html.append("<td></td>\n");
                html.append("</tr>\n");
                continue;
            }

            int firstCellNum = row.getFirstCellNum();
            int lastCellNum = row.getLastCellNum();

            // 각 셀을 순회하며 HTML로 변환
            for (int cellNum = firstCellNum; cellNum < lastCellNum; cellNum++) {
                Cell cell = row.getCell(cellNum);
                
                // 병합 셀 처리
                if (isCellInMergedRegion(cellNum, rowNum, mergedRegions)) {
                    CellRangeAddress mergedRegion = getMergedRegion(cellNum, rowNum, mergedRegions);
                    // 병합 셀의 첫 번째 셀만 출력 (나머지는 건너뜀)
                    if (mergedRegion.getFirstRow() == rowNum && mergedRegion.getFirstColumn() == cellNum) {
                        int rowspan = mergedRegion.getLastRow() - mergedRegion.getFirstRow() + 1;
                        int colspan = mergedRegion.getLastColumn() - mergedRegion.getFirstColumn() + 1;
                        String cellValue = getCellValueAsString(cell);
                        html.append(String.format("<td rowspan='%d' colspan='%d'>%s</td>\n", 
                            rowspan, colspan, escapeHtml(cellValue)));
                    }
                } else {
                    // 일반 셀 처리
                    String cellValue = getCellValueAsString(cell);
                    html.append("<td>").append(escapeHtml(cellValue)).append("</td>\n");
                }
            }

            html.append("</tr>\n");
        }

        html.append("</table>");
        return html.toString();
    }

    /**
     * 셀 값을 문자열로 변환
     * 
     * 셀 타입에 따라 적절히 변환:
     * - STRING: 문자열 그대로
     * - NUMERIC: 숫자 또는 날짜
     * - BOOLEAN: true/false
     * - FORMULA: 수식 결과값
     * - BLANK: 빈 문자열
     * 
     * @param cell 엑셀 셀
     * @return 문자열로 변환된 셀 값
     */
    private static String getCellValueAsString(Cell cell) {
        if (cell == null) {
            return "";
        }

        switch (cell.getCellType()) {
            case STRING:
                return cell.getStringCellValue();
            case NUMERIC:
                // 날짜 형식인지 확인
                if (DateUtil.isCellDateFormatted(cell)) {
                    return cell.getDateCellValue().toString();
                } else {
                    // 정수인지 소수인지 확인
                    double numericValue = cell.getNumericCellValue();
                    if (numericValue == (long) numericValue) {
                        return String.valueOf((long) numericValue); // 정수
                    } else {
                        return String.valueOf(numericValue); // 소수
                    }
                }
            case BOOLEAN:
                return String.valueOf(cell.getBooleanCellValue());
            case FORMULA:
                // 수식 결과값 가져오기 (문자열 우선, 실패 시 숫자)
                try {
                    return cell.getStringCellValue();
                } catch (Exception e) {
                    try {
                        return String.valueOf(cell.getNumericCellValue());
                    } catch (Exception ex) {
                        return cell.getCellFormula(); // 수식 그대로
                    }
                }
            case BLANK:
                return "";
            default:
                return "";
        }
    }

    /**
     * HTML 특수 문자 이스케이프
     * 
     * XSS 공격 방지를 위해 HTML 특수 문자를 이스케이프합니다.
     * 
     * @param text 원본 텍스트
     * @return 이스케이프된 텍스트
     */
    private static String escapeHtml(String text) {
        if (text == null) {
            return "";
        }
        return text.replace("&", "&amp;")
                  .replace("<", "&lt;")
                  .replace(">", "&gt;")
                  .replace("\"", "&quot;")
                  .replace("'", "&#39;");
    }
}
```

#### JsonlConverter.java

```java
/**
 * JSONL 변환 유틸리티
 * 
 * HTML과 이미지를 JSONL (JSON Lines) 형식으로 변환합니다.
 * 
 * JSONL 형식:
 * - 각 줄이 하나의 JSON 객체
 * - 여러 시트가 있으면 각 시트마다 한 줄씩
 * 
 * 예시:
 * {"image":"base64_string","html":"<table>...</table>"}
 * {"image":"base64_string","html":"<table>...</table>"}
 * 
 * 사용 라이브러리:
 * - Jackson ObjectMapper (JSON 직렬화)
 */
public class JsonlConverter {

    private static final ObjectMapper objectMapper = new ObjectMapper();

    /**
     * HTML과 이미지를 JSONL 한 줄로 변환
     * 
     * 형식: {"image": "base64_string", "html": "<table>...</table>"}
     * 
     * 주의사항:
     * - image는 base64 인코딩된 문자열 (프론트엔드에서 생성)
     * - html은 그대로 저장 (base64 인코딩하지 않음)
     * - image가 null이면 빈 문자열로 저장
     * 
     * @param htmlContent HTML 내용 (base64 인코딩하지 않음)
     * @param imageBase64 Base64로 인코딩된 이미지 (null 가능)
     * @return JSONL 한 줄 (JSON 문자열)
     */
    public static String toJsonlLine(String htmlContent, String imageBase64) {
        try {
            Map<String, String> payload = new LinkedHashMap<>();
            // 이미지 base64 (없으면 빈 문자열)
            payload.put("image", imageBase64 != null ? imageBase64 : "");
            // HTML은 그대로 저장 (base64 인코딩하지 않음)
            payload.put("html", htmlContent != null ? htmlContent : "");
            return objectMapper.writeValueAsString(payload);
        } catch (JsonProcessingException e) {
            throw new RuntimeException("JSONL 변환 중 오류가 발생했습니다.", e);
        }
    }

    /**
     * 여러 시트 데이터를 JSONL 형식으로 변환
     * 
     * 각 시트마다 JSONL 한 줄씩 생성하고, 줄바꿈(\n)으로 연결합니다.
     * 
     * 예시 (시트 2개):
     * {"image":"...","html":"<table>...</table>"}
     * {"image":"...","html":"<table>...</table>"}
     * 
     * @param sheets 시트 데이터 리스트
     * @return JSONL 형식의 문자열 (각 줄은 한 시트를 나타냄)
     */
    public static String toJsonl(List<ExcelToHtmlConverter.SheetData> sheets) {
        return sheets.stream()
                .map(sheet -> toJsonlLine(sheet.getHtmlContent(), sheet.getImageBase64()))
                .collect(Collectors.joining("\n"));
    }

    /**
     * 여러 시트 데이터를 JSONL 형식의 바이트 배열로 변환
     * 
     * 파일 다운로드를 위해 바이트 배열로 변환합니다.
     * 
     * @param sheets 시트 데이터 리스트
     * @return JSONL 형식의 바이트 배열 (UTF-8 인코딩)
     */
    public static byte[] toJsonlBytes(List<ExcelToHtmlConverter.SheetData> sheets) {
        return toJsonl(sheets).getBytes(StandardCharsets.UTF_8);
    }
}
```
